The long version

Three jobs that turned out to be one job.

↳ design → build → measure → repeat

Design school teaches you to finish at the file. D2C teaches you that the file is about 30% of the work. The other 70% is whether the page loads fast, whether the email renders in Outlook, whether the variant is set up right, and whether anyone bought anything.

So I learned the other 70%. I write the Liquid for the sections I design. I build the flows in Klaviyo instead of handing over a PNG. I set up the tests and I read the results, including the ones that say my idea was wrong.

A good page isn't the one that wins the Dribbble shot. It's the one still running six months later because nobody had a reason to replace it.

What clients tend to notice: things arrive on time, I ask about the offer before I ask about the brand colours, and I'll tell you when a section isn't worth building.
